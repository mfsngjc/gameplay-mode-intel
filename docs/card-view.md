# 全站资料卡片大小

2026-10-21，用户明确要求全站所有资料卡片加入“大图 / 小图”切换。

- 范围：玩法模式案例与基础更新、版本目录封面卡、地图目录、主题道具目录、收藏中的上述资料，以及四个平台和混合平台的 UGC 目录。动态信息行、时间线、版本正文与排名表格保持各自的信息结构；它们不是图片资料卡片。
- 公开控件统一为“大图 / 小图”按钮组，选中状态与键盘焦点可见。默认小图，浏览器保存最近的显式选择；跨栏目、检索、分页、刷新时继续使用。
- 大图沿用图片在上的图文卡；小图以文字为主体并保留缩略图。UGC 罗布乐思与我的世界图标为 64×64，CS2 与堡垒之夜为 112×63；其他资料使用适合各自内容的小尺寸预览，不改动来源图。所有小图保持原比例。
- 切换尺寸不清空搜索、分类、排序、收藏或已加载数量，不复位 UGC 页码；来源、详情、图片查看、地图操作与资料导出继续可用。
- `card-view.js` 提供唯一的共享状态：`CardView.get()`、`set(size)`、`subscribe(callback)` 与 `syncControls(root)`。尺寸值为 `large` / `small`，保存键为 `gameplay-card-size`；存储被禁用时本次页面内仍可切换。
- `body[data-card-size]` 驱动全站布局；按钮使用 `button[data-card-size]`，统一由共享模块处理。动态生成的 UGC 按钮在渲染后同步 `aria-pressed`。不再让旧的栏目 layout 参数覆盖全站选择。
- 构建白名单显式包含 `card-view.js` 与 `card-view.css`。尺寸偏好仅存本地浏览器，不写入作品数据、榜单快照或分析记录。

验收应覆盖：四个栏目与收藏的大图/小图、跨栏目记忆、重新载入、带搜索的 UGC 非首页切换、手机与平板的标题/按钮/缩略图、详情与地图操作，以及压缩发布版的共享模块加载。
