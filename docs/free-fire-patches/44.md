## 其他玩法与局外内容（目录摘要）

### 宠物成长及局外外观

宠物升级可解锁新皮肤和表情，并可在大厅互动；另有新服装及收藏品。宠物对局互动和表情另见局内小节。

原文目录：New Features > Pet System / New Contents

### 大厅、商城与操作界面

优化主大厅、队伍菜单与商店界面，限时商店增加每日限时折扣，重做充值菜单。另优化组队邀请、Fire Pass、收藏标签、活动标签和私信界面。

原文目录：System / Optimization
