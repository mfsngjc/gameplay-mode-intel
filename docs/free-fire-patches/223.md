## BR · 大逃杀

### 经典 BR Thompson

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：Gameplay > Thompson
- 时间：原文写明 Available in Classic mode；未单列日期，按公告日索引。

经典 BR 新增 Thompson 冲锋枪；此处数值是原文参数，不自行换算成每秒射速、换弹秒数或米数。CS 商店的替换另见 CS 小节。

- 经典 BR 新增 Thompson，伤害参数为 50。
- Thompson 射速参数为 77。
- Thompson 弹匣参数为 40。
- Thompson 精准度参数为 34。
- Thompson 换弹参数为 48。
- Thompson 射程参数为 33。

## CS · 枪王对决

### CS 排位季前赛

- 归属：CS · 枪王对决 / 常规调整
- 原文小节：Clash Squad > Rank Mode for Clash Squad
- 时间：时间来源：正文。Clash Squad - Pre Season 于 2020-04-09 15:00 SGT 开放。

- Clash Squad 新增独立于 BR Rank Mode 的排名机制；Clash Squad Casual 仍可游玩。

### CS 商店烟雾弹

- 归属：CS · 枪王对决 / 常规调整
- 原文小节：Clash Squad > Smoke Grenade
- 时间：原文写明 Available in Clash Squad Store；未单列日期，按公告日索引。

- 烟雾弹仅在 Clash Squad 商店提供。
- 每名玩家最多携带 1 枚烟雾弹。
- 烟雾弹价格为 300。
- 烟雾持续 25 秒。

### CS Casual 与 Ranked 商店更新

- 归属：CS · 枪王对决 / 常规调整
- 原文小节：Clash Squad > Clash Squad - Store Update
- 时间：原文写明 Available in Clash Squad Casual & Ranked；未单列日期，按公告日索引。

- CS 休闲与排位商店以 M60 替换 UMP。
- 以 Thompson 替换 CG-15。
- 以烟雾弹替换闪光弹。
- Kar98k 改为自带生物识别瞄具（Biometric Scope，说明性译名）。
- XM8 与 M1014 价格提高；正文未给出改后价格。
