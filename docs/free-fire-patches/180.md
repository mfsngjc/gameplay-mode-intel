## BR · 大逃杀

### 地图战利品新增 SKS、平底锅和巴冷刀

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：Patch Notes > New Features
- 时间：公告日期为 2018-01-08；正文预告 2018-01-09 06:00–14:30（UTC+8）停服维护，维护后更新客户端。预告维护时段不等于本资料已核实实际上线结果。

- SKS 作为自带 4 倍镜的狙击步枪加入地图战利品。
- 平底锅为短距离近战武器，可挡子弹；巴冷刀射程长于平底锅，也可挡子弹。

### 浅水减速与车辆地形调整

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：Patch Notes > New Features / Balance changes
- 时间：公告日期为 2018-01-08；正文预告 2018-01-09 06:00–14:30（UTC+8）停服维护，维护后更新客户端。预告维护时段不等于本资料已核实实际上线结果。

- 浅水区降低角色和载具移动速度，并加入靠近浅水区的音效。
- 车辆加速度略降，且更受不平地形影响；周围车辆噪声略降。

## 通用局内调整

### 自定义 HUD 与地图队友状态

- 归属：通用局内调整 / 常规调整
- 原文小节：Patch Notes > New Features
- 时间：公告日期为 2018-01-08；正文预告 2018-01-09 06:00–14:30（UTC+8）停服维护，维护后更新客户端。预告维护时段不等于本资料已核实实际上线结果。

通用调整的适用范围未逐模式列出；该公告未提供 CS 专属说明。

- 设置中可调整 HUD，包括开火按钮大小。
- 小地图显示队友被击倒、开火、驾驶和死亡，并显示附近移动载具。
- 武器、背包和拾取 HUD 图标放大以便点击。

### 开镜界面、敌人准星与 AWM 操作

- 归属：通用局内调整 / 常规调整
- 原文小节：Patch Notes > Balance changes/Optimizations
- 时间：公告日期为 2018-01-08；正文预告 2018-01-09 06:00–14:30（UTC+8）停服维护，维护后更新客户端。预告维护时段不等于本资料已核实实际上线结果。

通用调整的适用范围未逐模式列出；该公告未提供 CS 专属说明。

- 调整开镜时的界面；准星对准敌人时会改变颜色。
- 设置中可切换 AWM 的控制方式，重新提供此前的 AWM 操作方案。
