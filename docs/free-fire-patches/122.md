# Free Fire · Kalahari（2020 年 2 月补丁）

- 官方来源：[PATCH NOTES: KALAHARI](https://ff.garena.com/en/article/122/)
- 审阅日期：2026-09-19
- 11 个分类小节；38 项说明及表格行；1 张官方公告插图。

本篇 BR、CS 与通用局内更新已按官方正文复核。独立玩法及局外内容另列处置；未公布的日期、范围和单位明确保留信息缺口。

公告日期为 2020-02-25。正文仅给 02/28 的时刻，未标明时区；其余按公告日索引。

### 喀拉哈里地图上线与炼狱开放安排

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：New Map - Kalahari
- 时间：公告为 2020-02-25；正文预告 02/28 04:00 开放喀拉哈里经典模式，年份按公告年记录，未公布时区。

### 可移动治疗的吸入器

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：Gameplay > Inhaler
- 时间：原文写明 Available in Classic Mode；未单列日期，按公告日索引。

- 经典 BR 新增吸入器（Inhaler），可在移动时使用；官方将其标为试验性道具。
- 恢复数值原文写为 25 HP 和 EP，并括注上限 150；该句未拆分说明上限对 HP／EP 的适用关系。

### 经典 BR 的电动滑板

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：Gameplay > Electric Surfboard
- 时间：原文写明 Available in Classic Mode；未单列日期，按公告日索引。

- 电动滑板（Electric Surfboard）常规滑行速度参数为 4.65；原文对照的冲刺速度参数为 3.25，均未注明单位。
- 加速时速度参数为 12，未注明单位。
- 加速持续 3 秒。

### AWM 护甲伤害强化配件

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：Advanced Attachments > AWM - Armor-Piercer
- 时间：原文写明 Available in Classic Mode；未单列日期，按公告日索引。

- 经典 BR 的 AWM 护甲穿透配件（Armor-Piercer，说明性译名）对防御装备额外造成 300% 伤害；对玩家生命值没有额外伤害。

### 等离子枪过热强化配件

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：Advanced Attachments > PLASMA - Thermal Boost
- 时间：原文写明 Available in Classic Mode；未单列日期，按公告日索引。

- 经典 BR 的等离子枪过热强化配件（PLASMA Thermal Boost，说明性译名）使达到过热所需时间增加 33%，冷却时间减少 33%。
- 等离子枪越接近过热，伤害越高；原文未给具体变化函数或数值。

### 高峰时刻的炼狱开放时段

- 归属：BR · 大逃杀 / 常规调整
- 原文小节：New Map - Kalahari
- 时间：正文预告自 2020-02-28 起每日 18:00–22:00 开放，未注明时区。

仅适用于高峰时刻（Rush Hour）BR 变体，不表示普通 BR 和 CS 都按这一时段开放。

- 炼狱地图的高峰时刻（Rush Hour）自 2020-02-28 起每日 18:00–22:00 提供。

## CS · 枪王对决

## 通用局内调整

### Steffie 涂鸦区域减伤技能

- 归属：通用局内调整 / 常规调整
- 原文小节：Gameplay > New Character - Steffie
- 时间：原文写明 Available in Free Fire Store；未单列日期，按公告日索引。

- 新增涂鸦角色 Steffie；Painted Refuge 创建涂鸦区域，对爆炸伤害的减免随技能等级依次为 15／17／19／21／23／25%。
- 子弹伤害固定降低 5%；对应六级的持续时间依次为 5／6／7／8／9／10 秒。
- 冷却时间为 45 秒。

### AN94 属性调整

- 归属：通用局内调整 / 常规调整
- 原文小节：Gameplay > AN94
- 时间：公告日索引。

原文没有标明适用模式；不推定 BR 或 CS。

- AN94 伤害参数 38→36。
- AN94 射速提高 11%。
- AN94 最小射程提高，具体数值未说明。
- AN94 后坐力恢复速度提高 100%。
- AN94 移除枪口配件槽。

### XM8 伤害、操控与移动射击调整

- 归属：通用局内调整 / 常规调整
- 原文小节：Gameplay > XM8
- 时间：公告日索引。

原文没有标明适用模式；不推定 BR 或 CS。

- XM8 伤害参数 30→33。
- XM8 射速提高 18%。
- XM8 弹匣容量 30→25。
- XM8 射程降低 5，原文未说明单位。
- XM8 精准度降低 5%。
- XM8 开镜移动速度提高 15%，移动射击不再降低精准度。

### 排位物品池扩充

- 归属：通用局内调整 / 常规调整
- 原文小节：Gameplay > Weapons Added to Rank Mode
- 时间：公告日索引。

原文仅称 Rank Mode，没有单列 BR／CS 适用范围。

- 排位物品池加入双弹匣配件（Double Magazine，说明性译名）。
- 加入冰枪（Ice Gun），仅在空投出现。
- 加入 Kar98k 生物识别瞄具（Bio Scope，说明性译名）。
- 加入 VSS 撕裂弹配件（Ripper Bullet，说明性译名）。
- 加入 M14 狂怒核心配件（Rage Core，说明性译名）。

### 技能、冲刺、队伍语音与局内提示

- 归属：通用局内调整 / 常规调整
- 原文小节：Other Adjustments > Others
- 时间：公告日索引。

原文未逐项标明模式；不推定 BR 或 CS。

- 可把已拥有的宠物技能与其他技能互换。
- 激活技能不再中断冲刺。
- 可在语音聊天中静音选定队友。
- 开火按钮图标会随所用武器变化。
- 优化载具 HP 显示。
- 弹药耗尽时可选择自动切换武器。
- HP 较低时显示使用医疗包提示。
- 新增小地图自动缩放设置。

## 其他玩法与局外内容（目录摘要）

### Training Grounds

独立练习场于 2020-02-28 04:00 开放，公告称可测试所有武器并与朋友互动；不归入 BR、CS 或 shared 详录。

原文目录：New Map - Training Grounds

### Team Deathmatch 更新

独立玩法 Team Deathmatch：预设装备提供护甲和头盔，武器池加入新武器，地图加入空投（每局最多 10 个）及各战斗区域的新重生点。不得归为 Clash Squad。

原文目录：Gameplay > Team Deathmatch

### Friends List

好友列表新 UI、推荐好友优化和屏蔽好友申请属于社交/局外页面。

原文目录：Other Adjustments > Friends List

### Party

大厅邀请、入队请求、邀请码、移除队友和最近一起玩过的页面属于局外组队流程。

原文目录：Other Adjustments > Party
