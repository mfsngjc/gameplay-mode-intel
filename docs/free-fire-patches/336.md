## 通用局内调整

### Vector Akimbo、M82B 与 M4A1

- 归属：通用局内调整 / 常规调整
- 原文小节：Weapon and Balance
- 时间：本项未单列生效时刻，按公告日索引。

Vector 与 M4A1 明确适用 Classic 与 CS；M82B 明确 all modes/all maps。

- 双持 Vector 在经典 BR 与 CS 提供：伤害参数 22、弹匣 30 发、射速参数 0.08，原文未给射速单位；可安装枪口和枪托。
- Akimbo 使玩家可双手各持一把 Vector。
- 所有地图的 M82B 掉落率降低，原文未给比例。
- M4A1 在 Classic 与 Clash Squad：伤害28→29、射速+5%、有效射程+12.5%、最大后坐力-14%。

### P90 与高级武器

- 归属：通用局内调整 / 常规调整
- 原文小节：Weapon and Balance > P90 / Advanced Weapons
- 时间：公告日索引。
